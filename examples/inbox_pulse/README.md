# Inbox Pulse

Полезный Pill Stack-плагин для DevGram.

- показывает число непрочитанных чатов или сообщений;
- нажатие открывает следующий непрочитанный диалог;
- долгое нажатие переключает режим счётчика;
- умеет исключать заглушённые чаты;
- использует нативный градиент DevGram: фиолетово-синий при наличии непрочитанных и зелёно-бирюзовый, когда всё прочитано;
- корректно освобождает pill при reload и удалении плагина.

После установки виджет включается автоматически. Управлять им можно в настройках Pill Stack и на странице настроек самого плагина.
