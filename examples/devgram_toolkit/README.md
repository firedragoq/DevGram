# DevGram Toolkit

Рабочий пример Builder-style архитектуры для текущего DevGram runtime.

- `main.py` связывает lifecycle и настройки;
- `modules/` содержит пользовательские функции;
- `services/` хранит состояние;
- пакет устанавливается как обычный `.dgplugin`.

После установки зажмите текстовое сообщение и выберите один из пунктов `Toolkit`.
